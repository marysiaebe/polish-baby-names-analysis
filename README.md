# Polish Baby Names Analysis

## Overview

This project explores trends in the popularity of baby names in Poland between 2010–2014 and 2020–2024.

The analysis investigates how naming preferences have evolved over time, identifies long-term trends, and examines regional differences in the popularity of male and female names.

The final outcome is an infographic combining statistical analysis, data visualization and geographical mapping.

---

## Objectives

- Analyze changes in baby name popularity over time
- Compare male and female naming trends
- Identify emerging and declining names
- Explore regional differences across Polish voivodeships
- Present findings in the form of an infographic

---

## Dataset

Public datasets published by:

- dane.gov.pl
- Statistics Poland (GUS)

---

## Methods

The project included:

- data cleaning
- aggregation of annual statistics
- calculation of relative name frequencies
- trend analysis
- regional comparison
- data visualization
- map creation

---

## Key Findings

- Male naming trends changed more dynamically than female naming trends.
- Several male names entered the top rankings over the analyzed period.
- Female names showed greater long-term stability.
- Strong geographical clustering was observed in the popularity of selected names.
- Nikodem was the dominant male name across most Polish voivodeships in 2024.
